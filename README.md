# Life Expectancy: Stories in the Numbers

## Problem
Life expectancy varies wildly by country and status — we wanted clear, evidence-backed insights from public health data, not just pretty charts.

## What we built
A group EDA project covering cleaning, visualization, correlation, and inference on life expectancy and related health indicators (immunization, expenditure, development status, and more). Charts live in `Chart_Images/` and analysis in `life_expectancy_analysis.ipynb`.

## How to run
```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook life_expectancy_analysis.ipynb
```

## Stack
Python · pandas · matplotlib / seaborn · Jupyter

## Fun closer
Sometimes the strongest signal is not a fancy model — it is a carefully cleaned dataframe and a honest correlation plot.
